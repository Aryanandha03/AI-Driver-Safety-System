# Driver Monitoring System - Member 2

This module is responsible for:

- Eye detection
- Eye Aspect Ratio (EAR)
- Blink detection
- Prolonged eye closure
- Yawning detection
- Head pose estimation
- Looking-away detection
- Drowsiness analysis
- Distraction analysis

## Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
